# Contracts for avd-entra

Produces `entra-manifest.json` (logical group roles including optional Windows 365 user and dynamic Cloud PC device groups, dynamic device membership rules, Conditional Access baseline state, and Entra Kerberos readiness) consumed by `avd-intune`, `avd-m365`, `avd-azure` and `avd-power-platform`.

See [avd-ops decision 0009](https://avd-ops.dev/docs/decisions/0009-split-landing-zone-into-five-control-planes.html) and [decision 0012](https://avd-ops.dev/docs/decisions/0012-desktop-devops-for-avd-win365-and-intune.html).
